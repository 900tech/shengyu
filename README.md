# 声屿

个人本地音频智能创作工作台。面向没有专业音频编辑基础的独立音乐人，优先服务国风 DJ、Remix 和车载音乐。音频、歌词、模板和作品都留在本机；远程侧只能走纯文本指令和状态。

安装包里的文件名使用 `Shengyu`，打开后的窗口标题和界面名称是「声屿」。这样可以避开 Windows 安装器对非英文产品名的路径问题。

## 在 Windows 上安装

构建产物由 GitHub Actions 在 `windows-latest` 上生成，用户不需要安装 Node、Python、FFmpeg 或大模型。

1. 打开本仓库的 Actions，进入「Windows 构建与冒烟」。
2. 运行成功后下载名为 `shengyu-windows` 的产物。
3. 任选其一：
   - `Shengyu-Setup-0.2.0.exe`：安装到当前用户，并创建桌面快捷方式。
   - `Shengyu-Portable-0.2.0.exe`：免安装，双击即开。
4. 安装包没有代码签名。Windows SmartScreen 可能提示发布者未知，选择仍要运行即可。不需要配置签名证书也能完成安装。

0.2.0 不需要 Node、Python、FFmpeg 或模型密钥。核心路径离线可用：导入、试听、Remix、清洗、歌词仿写和导出都会在本机完成。榜单抓取需要网络，失败时界面保持空列表并说明原因。

## 0.2.0 能做什么

- **可播放结果**：Remix、Demo、清洗版和一键复刻都会生成 WAV。作品库里点「播放」即可听。没有导入文件时，按 BPM、调性和风格合成一段可听的示范，并混入你导入的波形。
- **导出路径**：导出、清洗并导出、歌词导出都会弹出系统保存对话框。取消保存不会冒充成功；作品库里的试听仍然在。
- **实际写出的格式是 WAV**。预设里的 MP3 / FLAC 是场景说明。安装包不附带编码器，所以不会假装写成这两种格式。抖音预设导出 60 秒，车载预设 24 秒，汽水预设 16 秒。库内试听默认 12 秒，模板试听 15 秒。
- **模板库**：可按风格、调性、版权和 BPM 筛选，并应用到创作中心或 Remix。
- **榜单**：桌面版抓取 [Apple Music 中国最常播放](https://rss.applemarketingtools.com/api/v2/cn/music/most-played/50/songs.json) 和 [Deezer 公开榜](https://api.deezer.com/chart/0/tracks)。只保留曲名、艺人、曲风、排名和时长，不下载音频。不需要 API key。
- **风格筛选**：曲风按本地五类字典映射。对不上的歌标成「未映射」，只在「全部」里出现。某个风格没有歌时列表为空，不会用别的歌填上。
- **一键复刻**：用选中风格的本地 BPM / 调性预设生成可播放 Demo，并写明这不是从原曲检测出来的。榜单没有公开 BPM。
- **歌词仿写**：创作中心用本地词典按文言密度仿写，可导出 txt，并可写入作品一起播放。不调用付费模型。
- **远程连接**：默认未连接。设置里填写 HTTPS 状态地址并测试成功后，才显示已连接。未授权指令即使在未连接时也会被拦截。本机不监听入站端口。

汽水音乐和网易云音乐没有可合法直接调用的公开榜单接口，所以不会把 Apple / Deezer 的结果标成这两家的数据。若你有自己的 HTTPS JSON 榜单，可在趋势页填写，格式可以是 `{ "entries": [{ "title": "", "artist": "", "style": "国风DJ" }] }`。

## 已知限制

- 人声分离是波形混入，不是神经网络分轨。
- 水印弱化是约 0.5% 的变速重写，不是频谱水印检测器。
- BPM / 调性来自本地波形估算；读不出波形时会标明占位，不会假装已经分析成功。
- 榜单抓取失败、浏览器预览、或某个风格没有映射结果时，页面会说明原因，列表为空。

## 本地开发

```bash
npm install
npm start
```

`npm start` 用 Electron 打开桌面窗口。界面脚本不允许向网络发请求。

只看界面时也可以：

```bash
npm run preview
```

然后打开 [声屿预览](http://127.0.0.1:43127)。

```bash
npm test
npm run smoke
```

`npm test` 检查参数字典、清洗签名、版权拦截、白名单和版本树。`npm run smoke` 用本机 Chrome 走查关键点击，并要求控制台没有错误。

| 条目 | 在界面上怎么看 |
| --- | --- |
| 1.1 视觉规范 | 左侧六个入口：控制台、音频处理、模板库、作品库、远程指令、设置。浅色背景 `#F7F8FA`，主色 `#34C7BE`。设置或左下角可切换深色。没有多轨波形编辑、旋钮和推子 |

| 1.3 清洗规则单源 | 在元数据清洗里取消一项。Remix 处理选项和作品库批量导出会显示同一个规则指纹 |

| 1.5 版本树 | 用示例原曲生成 Remix 后，打开作品库，「月下归舟」下面会出现新版本，不用手动归类 |

## 第二阶段已经能演示的部分

- 控制台「查看趋势」：桌面版抓取 Apple Music 与 Deezer 的公开文本。失败时列表为空。抓到之后才能保存创作模板。
- 作品详情里的发行物料：汽水音乐和网易云音乐各有歌名、标签、100 字以内简介和发布时间，可以改、可以复制。这两套物料是本地文案模板，不是榜单抓取结果。
- 作品库顶部三套导出预设：汽水音乐完整版、抖音 60 秒卡点版、车载无损版。可以另存自定义预设。切换后时长和响度跟着变，写出的文件是 WAV。
- Remix 可多选模板，一次生成多个可播放版本，命名为「原曲名 · 版本类型」，并挂回原曲。

## 已知 stub

- 人声分离不是神经网络。导入的波形会按 BPM 对齐后混进风格节奏。
- 导出文件是 WAV。`fileWritten` 只在保存对话框写入成功后变为 true。
- 榜单只来自 Apple Music 与 Deezer 的公开文本，或你填写的 HTTPS JSON。失败时不使用样例。
- 远程「已连接」只在 HTTPS 状态地址探测成功后出现。
- 15 秒模板试听是当场合成的 WAV，结束后不留文件。

## 下一阶段从哪里接

后续如果要加深，仍沿用现有参数和清洗规则：

- 读不出波形时才会退回 `stubAnalyze`，界面会标明没读出波形。
- 人声分离若要换成模型，仍只在本机运行，不上传音频。
- 若要真正的 MP3 / FLAC，需要把编码器放进安装包，不能再要求用户另装运行时。
- 榜单继续只拉公开文本，禁止下载音频。

第三阶段里的参数快照、指令模板、15 秒预览和批量操作已经能走通，并且会生成可播放 WAV。

第四阶段还没做：作品数据报表、发行日历、灵感素材库、定时任务。

## 构建

推送到 `main` 或打开 Pull Request 时，`.github/workflows/windows.yml` 会先在 Ubuntu 上跑测试和浏览器走查，再在 Windows 上打包。产物名是 `shengyu-windows`，里面是 `Shengyu-Setup-0.2.0.exe` 和 `Shengyu-Portable-0.2.0.exe`。不需要签名证书。
